# 初始化流程详细设计

## 流程总览

初始化是一次**4轮共创对话**，不是表格填写。每轮你作为编辑提供3个方向，用户选择，你根据选择积累"小说DNA"，最终生成完整的项目文件。

用户也可以在任何一轮说"我有别的想法"——你要灵活接收并整合进已有选择中。

---

## 开场白（固定）

当用户开始新项目时，使用以下开场：

```
很好，我们来一起创作一部推理小说。

我会问你4个问题，每次给你3个方向选择。
不需要全想清楚——我们是在做决定的过程中发现这部小说的样子。

准备好了吗？我们从"故事的气候"开始。
```

---

## 第1轮：世界感

**目的**：确定时代背景与氛围基调，这决定语言风格、社会关系的底层逻辑。

```
【第1轮：这个故事生活在什么样的空气里？】

背景时代决定了一切——人物说话的方式、案件能被隐瞒的原因、
侦探能调动的资源。选一个让你感觉"对"的世界：

A. 民国时代（1912-1949）
   → 乱世之中，传统与变革碰撞。租界、军阀、旧式家族并存。
     信息靠信件与口耳相传，身份可以伪造，秘密可以沉埋。
     适合：家族恩怨、谍影重重、旧社会秘辛。

B. 千禧年前后（1980-1999）
   → 改革开放浪潮中，旧秩序松动但尚未完全消解。
     固定电话是主要通讯手段，互联网刚刚萌芽。
     国企改制、人口流动、城乡夹缝中藏着无数故事。
     适合：社会转型期的阵痛、人情社会的暗流、小城旧事。

C. 当代都市（2010年代至今）
   → 监控摄像、手机记录、社交媒体构成信息迷宫。
     罪行发生在写字楼、公寓、网络空间。
     嫌疑人有律师意识，警察受程序约束。
     适合：职场权谋、家族遗产、互联网暗面。

（任何一个时代都可以叠加「封闭场景」——暴风雪山庄、孤岛、密闭列车，
凶手被困在有限的几个人中间。选完时代后告诉我是否需要叠加。）

（也可以告诉我你有完全不同的想法）
```

**选择记录**：将用户选择存入 `世界感` 变量，继续第2轮。

## 第2轮：案件骨架

**目的**：确定诡计的"性质"——不是具体设计，而是读者解谜时的体验类型。

```
【第2轮：这个谜题的核心是什么类型的"欺骗"？】

推理小说里，诡计不只是"怎么杀人"，更是"如何欺骗读者的认知"。
三种根本不同的欺骗方式：

A. 物理诡计（不可能犯罪）
   → 密室、不在场证明、时间错位。
     读者在挑战：这在物理上是否可能？
     适合：严密的逻辑游戏，解谜的快感在"啊原来如此"的瞬间。

B. 心理诡计（叙述欺骗）
   → 读者一直在看，但看到的是经过选择的信息。
     凶手可能一直在场，只是你的视角被操控了。
     适合：叙述者不可靠、视角的盲区、读者与作者的智力博弈。

C. 社会诡计（动机的隐藏）
   → 物理上没有谜题，谜题是：谁有理由这么做？为什么？
     案件揭开一个家族、一个机构、一段历史的脓包。
     适合：社会派，人性比逻辑更重要，真相令人悲哀而非惊叹。

（也可以告诉我你有完全不同的想法）
```

---

## 第3轮：核心张力

**目的**：确定侦探与案件之间的情感关系——这是故事的"发动机"。

```
【第3轮：侦探为什么非查不可？】

推理小说最动人的部分不是诡计，而是侦探与真相之间的张力。
是什么力量驱使他/她走到最后？

A. 职业义务 + 个人代价
   → 警察或职业侦探，查案是工作，但这个案子触碰了
     他/她不想触碰的东西——家人、过去的失败、某个承诺。
     张力来自：职责要求他继续，情感让他想停下。

B. 局外人卷入
   → 主角原本与案件无关，却因为某个偶然成为唯一
     知道某个关键信息的人，或者被错误地怀疑。
     张力来自：越查越危险，但不查无法自证清白或保护某人。

C. 侦探认识凶手
   → 从一开始就有强烈的预感或怀疑，但那个人是朋友、
     家人、或自己尊敬的人。查案就是在拆解一段关系。
     张力来自：真相会伤人，但谎言更令人窒息。

（也可以告诉我你有完全不同的想法）
```

## 第4轮：结局基调

**目的**：确定故事最终给读者留下什么感受。这影响全篇的信息投放策略。

```
【第4轮：当一切揭开，读者应该感受到什么？】

结局的基调从第一章就开始在暗处运作。
你希望读者合上书时，心里是什么味道？

A. 正义的代价
   → 真相被揭露，凶手受到追究，但这个过程摧毁了某些
     本不该被摧毁的东西。正确的结局，沉重的代价。
     读者感受：值得，但心里有个洞。

B. 灰色的真相
   → 凶手有自己的逻辑，受害者未必无辜，
     正义与法律之间存在裂缝。侦探选择了某个答案，
     但不是唯一的答案。
     读者感受：不安、持续思考、没有简单结论。

C. 救赎与和解
   → 案件的核心是一段被误解的关系或一个无法开口的秘密。
     真相揭开不是为了惩罚，而是为了让某些人终于可以放下。
     读者感受：悲伤但释然，像一场迟到的告别。

（也可以告诉我你有完全不同的想法）
```

## 4轮完成后：生成项目文件

收集到4个选择后，执行以下步骤：

### 步骤1：总结确认
```
好，我们来看看这部小说的轮廓：

- 世界：[用户选择的概括]
- 诡计性质：[用户选择的概括]
- 核心张力：[用户选择的概括]
- 结局基调：[用户选择的概括]

在我开始生成项目文件之前，还有几个必要信息需要你提供：

1. 这部小说叫什么名字？（或者暂定名）
2. 主角叫什么？大概是什么样的人？（一两句话就够）
3. 案件是什么？（死亡？失踪？盗窃？一句话描述就行）

这三个问题你可以一起回答，也可以让我帮你提供选项。
```

### 步骤2：生成所有meta文件

获取基本信息后，依次生成（读取对应模板）：

1. **`meta/project_info.md`** - 记录项目名称、类型、4轮选择
2. **`meta/style_guide.md`** - 风格宪法（读取 `templates/style_guide_template.md`）
3. **`meta/truth.md`** - 真相文档（读取 `templates/truth_template.md`）
4. **`meta/clues.md`** - 线索地图（读取 `templates/clues_template.md`）
5. **`meta/characters.md`** - 角色档案（读取 `templates/characters_template.md`，至少包含主角、嫌疑人和1-2个关键配角）
6. **`meta/outline.md`** - 宽松大纲（建议章节数和节奏分布）
7. **`meta/session_log.md`** - 空日志文件，等待第一章完成后填入

### 步骤3：创建项目目录

在项目根目录的 `novels/` 下创建项目：
```
novels/{项目名}/
├── meta/        （上述7个文件）
└── drafts/      （空目录，等待第一章）
```

### 步骤4：邀请开始写作
```
项目已创建完成：{项目路径}

你的小说《{书名}》已经有了骨架。

现在有两个方向：
- 输入 /write 直接开始第一章
- 输入 /plan 先讨论前三章的走向

你说了算。
```

# 爱情题材：写作/封存/审阅钩子

> 核心协议（writing_loop.md / auto_agents.md）在标注触点处注入本文件对应钩子的全文。
> 投放物分类学（ES / DS / AS）见本包 craft.md，此处引用不重定义。

## write_preflight（写作前行为预检）

在涉及情感决定性转折（表白/分离/和解）的场景前，先用一句话回答：
"[角色名]此时对对方的真实认知是[X]，他/她的情感逻辑和自我保护机制，会让他/她做出什么行为？"
如果计划中的剧情要求角色做出与其情感逻辑不符的行为，必须先补写情感积累，让转变有迹可循。

## signal_budget（每章信号投放预算与原则）

- 每章最多投放 1 个明确的情感信号（ES，Emotional Signal）
- 可附带 1 个"反向信号"（DS，退缩信号，误导读者认为感情倒退）
- 信号投放以 outline.md 本章「应投信号」计划为准（ES-/DS- 编号）；若实际偏离计划，必须显式说明原因（交互模式写入写作后记，自动模式写入 `<segment_meta>`），**禁止无声遗漏**
- 情感信号必须嵌入场景/动作/对话，不得以叙述者口吻直接点明
- ES 与 DS 交替投放才有重量——靠近之后需要退缩
- 每次投放后立即更新 `meta/romance_clues.md`（本题材 signal_doc）的状态

## showing_checklist（Showing 自查，仅报命中项）

- 通用：□ 叙述者直接说明人物的情绪 □ 人物说出时代错位的哲理句
- 题材专项：□ 角色直接说出感情状态 □ 障碍无积累突然消解 □ 对白与内心完全一致

## seal_check（章节封存第三步核对）

登记本章实际投放的信号（含正文摘录）并更新状态后，执行三类核对：

1. **信号预算核对**（对照 outline.md 本章计划）：
   - 计划投放的 ES-/DS- 是否已投？未投 → 就地补投，或显式修改 outline 计划并在「章节计划变更记录」中写明原因。**禁止无声遗漏**
   - 计划化解的 DS 是否已化解？计划揭示的秘密是否已揭？同上
2. **弧线核对**（对照 relationship_arc.md）：
   - 本章结束时两人的距离是否符合弧线该章的情感状态目标（靠近 / 后退 / 停滞）？偏离 → 就地调整，或显式修改 outline 计划并记录原因。**禁止无声遗漏**
   - 主角的真实情感进度（动心/确认/退缩）是否与「双方真实情感时间线」一致？正文是否提前泄露了时间线中尚未到达的状态？
3. **结局章断言**：若下一章进入结局章（依据第4轮结局基调）：
   - 逐条断言关键 ES 均已投放——读者的情感积累足以支撑结局的重量，未投放的必须在本章内补投
   - 逐条断言最后的 DS 已被化解，或被明确保留为结局基调的一部分（遗憾/开放型结局可保留未化解的张力）；有缺口的在本章内补齐

核对完成后回写 outline.md 本章「实际执行」字段（已完成 / 偏差及原因）。

## review_dims（责任编辑 B 维度：读者情感模拟）

切换至不持有 relationship_arc.md 的视角（普通读者视角）。
- 此刻对两个主角的关系进展有什么期待和判断？
- 哪个情感信号"太明显"或"太刻意"？
- 哪段对话的感情克制度合适/过度/不足？

## full_review（全稿两轮审阅题材部分）

### 第一轮专项核查（E 项·情感积累核查）

- 关键情感信号（ES）回看是否成立：每次靠近是否有前置的行为/细节积累，还是"作者需要所以爱上了"？
- DS 的化解是否付出代价：角色是否改变了某个认知或放下了某个保护壳，还是障碍被情节便利消解？
- 关系基准线是否在第 1-2 章建立：读者是否先看到"正常"，才可能感知"不正常"？
- 双视角项目：两个视角的信息差是否被真正利用（制造读者知情而当事人不知的张力），而非仅是轮换叙述？

### 第二轮输出格式（爱情版）

**目标**：从资深爱情小说编辑视角判断整部作品的情感真实性与读者体验。
**视角**：不持有 relationship_arc.md，以第一次读稿的编辑身份进行判断。
**输入**：全部 `{project_dir}/drafts/chXX.md` 文件

```
【第二轮审阅：文学编辑评审】

**核心判断**
（1-2句话，直接给出总体评价）

**真正的优势**
（2-3点，每点必须引用具体章节或对白作为依据）

**情感节奏问题**
（两个人关系的推进，是否有时候太快/太慢/缺乏积累？按章节指出）

**角色情感真实性**
（两个主角在情感判断、自我保护、表达方式上，是否前后一致、符合人性？）

**读者情感体验预判**
（读者会在哪里共情？哪里会觉得"这也太假了"？包括正面和负面判断）

**如果只能改一件事**
（最影响情感说服力的单一问题）
```

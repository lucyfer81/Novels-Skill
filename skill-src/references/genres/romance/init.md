# 爱情题材：初始化脚本

> 核心流程（交互停止契约、开场白、语言选择、步骤1-4）见 `references/init_flow.md`；本文件只定义题材部分。
> 所有问题脚本逐字使用，不得自行改写标题、引导语和选项。

## 第1轮：关系的土壤

**目的**：确定两个主角相遇、相处的时代和环境背景，这决定他们能做什么、不能做什么。

```
【第1轮：这段感情生长在什么样的土壤里？】

背景决定了两个人如何相遇、如何误解、如何靠近。
选一个让你感觉"对"的世界：

A. 当代都市职场
   → 写字楼、差旅、项目截止日。感情在压力与距离中生长，
     人们擅长用忙碌掩盖情绪，一条消息可以发出去，也可以删掉。
     适合：相爱相杀、权力关系、重逢。

B. 校园或青春时代
   → 共享食堂、社团、考试季。感情直接且脆弱，
     一次没有回复的消息可以在心里放三年。
     适合：初恋、错过与重逢、成长的代价。

C. 异地 / 跨文化
   → 时差、语言障碍、不同的生活习惯。距离制造了浪漫，
     也制造了误解。每次见面都像在倒计时。
     适合：跨越重重阻碍、分离与抉择、两种生活方式的碰撞。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`世界感` → 继续第2轮。

## 第2轮：感情的阻力

**目的**：确定两个主角之间最核心的障碍类型——这是故事的发动机。

```
【第2轮：是什么让这段感情不能顺利发生？】

爱情故事里，障碍的性质决定了一切的走向。
选一种最能打动你的阻力：

A. 外部阻力（身份 / 处境 / 第三方）
   → 家庭反对、竞争关系、前任的存在、朋友间的纠葛。
     两个人本身是合适的，但外部环境不允许。
     感情推进靠的是勇气和选择。

B. 内部阻力（误解 / 心理创伤 / 自我保护）
   → 有人不敢相信对方真的喜欢自己；
     有人因为过去的伤害，主动在感情里设防；
     有人把爱情理解成了负担。
     感情推进靠的是自我突破和信任的建立。

C. 时机阻力（错过 / 时差 / 选择冲突）
   → 在对的地方遇见，在错的时间点。
     一个要离开，一个刚刚准备好。
     感情推进靠的是等待、放手，或追上去。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`阻力类型` → 继续第3轮。

## 第3轮：叙事视角

**目的**：确定故事用谁的眼睛讲述，这影响读者与哪个角色的亲密度。

```
【第3轮：我们跟着谁的心跳走？】

视角不只是技术问题——它决定了读者会爱上哪个角色，
以及这个故事最核心的情感来自哪里。

A. 单一视角（跟着其中一人）
   → 读者和这个角色同步：他/她不知道的，读者也不知道。
     另一方变得神秘，一个眼神就可以被解读很久。
     适合：暗恋、误解、自我认知的成长。

B. 双视角轮换（两个人各有章节）
   → 读者比两个主角都"知道得多"——看着他们彼此误解，
     同时知道双方其实都在乎。这种反差制造甜蜜的痛苦。
     适合：错位的感情、两种内心世界的对比。

C. 旁观者视角（朋友 / 家人 / 同事）
   → 爱情发生在别人眼里。旁观者看得清楚，当事人却看不见。
     这个视角自带讽刺感，也自带温柔。
     适合：群像故事、从外向内写感情。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`叙事视角` → 继续第4轮。

## 第4轮：结局基调

**目的**：确定这个故事最终给读者留下的情感重量。

```
【第4轮：合上书时，读者心里是什么味道？】

A. 在一起（温暖圆满）
   → 两个人克服了障碍，走到一起。
     但"在一起"不是终点——最后的章节写的是：
     他们怎么选择彼此的那一刻。
     读者感受：被治愈，相信爱情值得。

B. 遗憾（错过或放手）
   → 感情是真实的，但时机、选择、或现实不允许。
     不是谁的错，是生活的形状就是这样。
     读者感受：悲伤但不怨恨，会想到自己的某段往事。

C. 开放（未完成，留白）
   → 故事在一个"可能性"里结束——没有明确答案。
     读者自己决定相信什么。
     读者感受：意犹未尽，有点不甘心，但也觉得这样刚好。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`结局基调` → 进入"4轮完成后：生成项目文件"流程。

## 项目文件生成清单

依次生成（读取本包 `templates/` 下对应模板）：

1. **`meta/project_info.md`** - 记录4轮选择（第2轮为"阻力类型"、第3轮为"叙事视角"）、三项基本信息、genre、language
2. **`meta/style_guide.md`** - 风格宪法（读取 `templates/romance_style_guide_template.md`；模板已内置爱情版的基础定位、叙事规则、对话/描写原则、绝对禁止项、对白情感检查与主角情感盲区字段，直接按4轮选择填充即可）
3. **`meta/relationship_arc.md`** - 关系弧线（读取 `templates/relationship_arc_template.md`；本题材无"真相文档"，关系弧线即 core_doc）
4. **`meta/romance_clues.md`** - 情感信号地图（读取 `templates/romance_clues_template.md`）
5. **`meta/characters.md`** - 角色档案（读取 `templates/romance_characters_template.md`）
6. **`meta/outline.md`** - 章节大纲（读取 `templates/outline_template.md`；每章使用爱情版字段：应投信号（ES/DS 编号）、弧线操作、应揭秘密、应化解退缩、章末钩子，并与 relationship_arc.md 的情感信号投放总表及情感时间线一致）
7. **`meta/session_log.md`** - 空日志文件，等待第一章完成后填入

## outline 章节节奏说明

```
第1-2章：相遇与基准线建立（展示两人各自的日常，以及第一次真实接触）
第3-4章：接近与第一个"错误信号"（靠近，但同时埋下误解的种子）
第5-6章：第一次情感危机（阻力开始真正起作用）
第7章：低谷或转折点（两人关系最远的时刻，或认知的转变）
第8-9章：重新靠近（因为某个事件或选择，距离缩短）
第10-11章：真正的障碍正面交锋（两人必须做出选择）
第12章：结局（根据第4轮选择执行对应结局基调）
```

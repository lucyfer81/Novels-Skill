# 爱情题材：初始化脚本

> 核心流程（交互停止契约、开场白、语言选择、步骤1-4）见 `references/init_flow.md`；本文件只定义题材部分。
> 所有问题脚本逐字使用，不得自行改写标题、引导语和选项。

## 第1轮：关系模式

**目的**：确定故事的核心关系开局（trope）——这是爱情小说的第一分类轴，且自带故事的阻力配比（外部处境 / 内心防御 / 时机错位的主次）。

```
【第1轮：这是一个什么样的爱情故事？】

爱情小说最先被记住的，不是发生在哪里，
而是两个人以什么关系开始。选一个你最想写的开局：

A. 欢喜冤家（对立立场）
   → 竞争对手、立场冲突、互相看不顺眼。
     推进靠在争吵中一点点看见对方真实的样子：
     嘴上不饶人，行动却越来越诚实。
     阻力配比：外部对立 + 各自的自尊。

B. 破镜重圆（旧账未了）
   → 分开过、错过过、或有一段没人再提的过去。
     重逢时表面平静，旧账都在暗处。
     推进靠把当年的误解一道一道开完。
     阻力配比：内心防御 + 时机。

C. 双向暗恋 / 错位（信息差）
   → 两个人都在乎，都以为对方不在乎。
     读者比当事人知道得多，眼看他们错过又靠近。
     推进靠勇气，和一次次差一点就说出口的坦白。
     阻力配比：自我怀疑与误解。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`关系模式` → 继续第2轮。

## 第2轮：背景土壤

**目的**：确定两个主角相遇、相处的时代和环境背景，这决定他们能做什么、不能做什么。

```
【第2轮：这段感情生长在什么样的土壤里？】

背景决定了两个人如何相遇、如何误解、如何靠近。
选一个让你感觉"对"的世界：

A. 当代都市
   → 写字楼、出租屋、差旅、深夜的消息。
     人们擅长用忙碌掩盖情绪，
     一条消息可以发出去，也可以删掉。
     适合：职场摩擦、成年人的分寸与试探。

B. 校园或青春时代
   → 共享食堂、社团、考试季。感情直接且脆弱，
     一次没有回复的消息可以在心里放三年。
     适合：初恋、错过与重逢、成长的代价。

C. 古风 / 年代
   → 旧式家族、礼数与规矩、书信与等待。
     感情藏在称谓和分寸里，一步走错就是闲话。
     适合：家族恩怨、包办与自由之间、乱世离合。

（异地、跨文化等处境可以叠加在任何一个背景上——选完背景后告诉我是否需要叠加）
（也可以告诉我你有完全不同的想法）
```

**选择记录**：`背景土壤`（含叠加处境，如有）→ 继续第3轮。

## 第3轮：情感基调

**目的**：确定全书的甜虐刻度——这是与读者的预期契约，决定靠近/退缩的配比与语言纪律。

```
【第3轮：这个故事的情感基调是什么？】

基调是和读者的契约：翻开第一页之前，
读者就知道自己将被如何对待。选你要的那种：

A. 甜宠治愈
   → 感情线整体明亮，阻碍是小的、暖的。
     靠近多于退缩，糖里可以有一点酸，但不苦。
     读者感受：被治愈，相信爱情值得。

B. 深情虐恋
   → 感情是真的，消耗也是真的。
     靠近与退缩反复拉扯，误会与牺牲都有重量。
     读者感受：心疼、揪心，意难平或苦尽甘来。

C. 现实向（半糖半苦）
   → 爱情服从生活的形状：现实条件、时间、
     各自的人生进度都会来搅局。
     读者感受：真实，会想到自己或身边人的故事。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`情感基调` → 继续第4轮。

## 第4轮：结局基调

**目的**：确定这个故事最终给读者留下的情感重量。

```
【第4轮：合上书时，读者心里是什么味道？】

A. 在一起（温暖圆满）
   → 两个人克服了障碍，走到一起。
     但"在一起"不是终点——最后的章节写的是：
     他们怎么选择彼此的那一刻。
     读者感受：被治愈，相信爱情值得。

B. 遗憾（错过或放手）
   → 感情是真实的，但时机、选择、或现实不允许。
     不是谁的错，是生活的形状就是这样。
     读者感受：悲伤但不怨恨，会想到自己的某段往事。

C. 开放（未完成，留白）
   → 故事在一个"可能性"里结束——没有明确答案。
     读者自己决定相信什么。
     读者感受：意犹未尽，有点不甘心，但也觉得这样刚好。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`结局基调` → 进入"4轮完成后：生成项目文件"流程。

## 叙事视角：编辑推荐（不占提问轮次）

叙事视角是工艺决策而非分类轴，由助手按第1轮关系模式推荐，随基本信息收集一并确认，不单独占一轮提问：

- **欢喜冤家** → 双视角轮换（放大立场反差与"原来他/她早就心软"的翻转），或单一视角（保持对立张力）
- **破镜重圆** → 单一视角为主（保住旧账的信息差），关键旧事可用插入章切换
- **双向暗恋 / 错位** → 双视角轮换（读者知道双方都在乎，才有"甜蜜的痛苦"）
- **自定义模式** → 按"信息差放在谁身上"决定；旁观者视角仅在用户明示时使用

推荐结果与理由写入 style_guide.md；用户在基本信息收集时表达过偏好则从其选择。

## 项目文件生成清单

依次生成（读取本包 `templates/` 下对应模板）：

1. **`meta/project_info.md`** - 记录4轮选择（第1轮为"关系模式"、第2轮为"背景土壤"（含叠加处境）、第3轮为"情感基调"）、三项基本信息、确认后的叙事视角、genre、language
2. **`meta/style_guide.md`** - 风格宪法（读取 `templates/romance_style_guide_template.md`；由第2轮背景轴取语言素材、第3轮基调轴取情感纪律正交合成，合成规则见本包 craft.md；叙事视角按本文件「叙事视角：编辑推荐」的确认结果填入并注明理由；模板已内置爱情版的基础定位、叙事规则、对话/描写原则、绝对禁止项、对白情感检查与主角情感盲区字段，直接按4轮选择填充即可）
3. **`meta/relationship_arc.md`** - 关系弧线（读取 `templates/relationship_arc_template.md`；本题材无"真相文档"，关系弧线即 core_doc；「感情障碍的真相层」以第1轮关系模式自带的阻力配比为基础具体化，配比定义见本包 craft.md）
4. **`meta/romance_clues.md`** - 情感信号地图（读取 `templates/romance_clues_template.md`）
5. **`meta/characters.md`** - 角色档案（读取 `templates/romance_characters_template.md`）
6. **`meta/outline.md`** - 章节大纲（读取 `templates/outline_template.md`；每章使用爱情版字段：应投信号（ES/DS 编号）、弧线操作、应揭秘密、应化解退缩、章末钩子，并与 relationship_arc.md 的情感信号投放总表及情感时间线一致）
7. **`meta/session_log.md`** - 空日志文件，等待第一章完成后填入

## outline 章节节奏说明

```
第1-2章：相遇与基准线建立（展示两人各自的日常，以及第一次真实接触）
第3-4章：接近与第一个"错误信号"（靠近，但同时埋下误解的种子）
第5-6章：第一次情感危机（阻力开始真正起作用）
第7章：低谷或转折点（两人关系最远的时刻，或认知的转变；
        具体形态受第3轮情感基调调制——甜宠=最远的靠近而非破裂，
        虐恋/现实向=真正的破裂或离开）
第8-9章：重新靠近（因为某个事件或选择，距离缩短）
第10-11章：真正的障碍正面交锋（两人必须做出选择）
第12章：结局（根据第4轮选择执行对应结局基调）
```

# 推理题材：初始化脚本

> 核心流程（交互停止契约、开场白、语言选择、各步骤）见 `references/init_flow.md`；本文件只定义题材部分。
> 所有问题脚本逐字使用，不得自行改写标题、引导语和选项。

## 第1轮：世界感

**目的**：确定时代背景与氛围基调，这决定语言风格、社会关系的底层逻辑。

```
【第1轮：这个故事生活在什么样的空气里？】

背景时代决定了一切——人物说话的方式、案件能被隐瞒的原因、
侦探能调动的资源。选一个让你感觉"对"的世界：

A. 民国时代（1912-1949）
   → 乱世之中，传统与变革碰撞。租界、军阀、旧式家族并存。
     信息靠信件与口耳相传，身份可以伪造，秘密可以沉埋。
     适合：家族恩怨、谍影重重、旧社会秘辛。

B. 千禧年前后（1980-1999）
   → 改革开放浪潮中，旧秩序松动但尚未完全消解。
     固定电话是主要通讯手段，互联网刚刚萌芽。
     国企改制、人口流动、城乡夹缝中藏着无数故事。
     适合：社会转型期的阵痛、人情社会的暗流、小城旧事。

C. 当代都市（2010年代至今）
   → 监控摄像、手机记录、社交媒体构成信息迷宫。
     罪行发生在写字楼、公寓、网络空间。
     嫌疑人有律师意识，警察受程序约束。
     适合：职场权谋、家族遗产、互联网暗面。

（任何一个时代都可以叠加「封闭场景」——暴风雪山庄、孤岛、密闭列车，
凶手被困在有限的几个人中间。选完时代后告诉我是否需要叠加。）

（也可以告诉我你有完全不同的想法）
```

**选择记录**：将用户选择存入 `世界感` 变量，继续第2轮。

## 第2轮：案件骨架

**目的**：确定诡计的"性质"——不是具体设计，而是读者解谜时的体验类型。

```
【第2轮：这个谜题的核心是什么类型的"欺骗"？】

推理小说里，诡计不只是"怎么杀人"，更是"如何欺骗读者的认知"。
三种根本不同的欺骗方式：

A. 物理诡计（不可能犯罪）
   → 密室、不在场证明、时间错位。
     读者在挑战：这在物理上是否可能？
     适合：严密的逻辑游戏，解谜的快感在"啊原来如此"的瞬间。

B. 心理诡计（叙述欺骗）
   → 读者一直在看，但看到的是经过选择的信息。
     凶手可能一直在场，只是你的视角被操控了。
     适合：叙述者不可靠、视角的盲区、读者与作者的智力博弈。

C. 社会诡计（动机的隐藏）
   → 物理上没有谜题，谜题是：谁有理由这么做？为什么？
     案件揭开一个家族、一个机构、一段历史的脓包。
     适合：社会派，人性比逻辑更重要，真相令人悲哀而非惊叹。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`诡计性质` → 继续第3轮。

## 第3轮：核心张力

**目的**：确定侦探与案件之间的情感关系——这是故事的"发动机"。

```
【第3轮：侦探为什么非查不可？】

推理小说最动人的部分不是诡计，而是侦探与真相之间的张力。
是什么力量驱使他/她走到最后？

A. 职业义务 + 个人代价
   → 警察或职业侦探，查案是工作，但这个案子触碰了
     他/她不想触碰的东西——家人、过去的失败、某个承诺。
     张力来自：职责要求他继续，情感让他想停下。

B. 局外人卷入
   → 主角原本与案件无关，却因为某个偶然成为唯一
     知道某个关键信息的人，或者被错误地怀疑。
     张力来自：越查越危险，但不查无法自证清白或保护某人。

C. 侦探认识凶手
   → 从一开始就有强烈的预感或怀疑，但那个人是朋友、
     家人、或自己尊敬的人。查案就是在拆解一段关系。
     张力来自：真相会伤人，但谎言更令人窒息。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`核心张力` → 继续第4轮。

## 第4轮：结局基调

**目的**：确定故事最终给读者留下什么感受。这影响全篇的信息投放策略。

```
【第4轮：当一切揭开，读者应该感受到什么？】

结局的基调从第一章就开始在暗处运作。
你希望读者合上书时，心里是什么味道？

A. 正义的代价
   → 真相被揭露，凶手受到追究，但这个过程摧毁了某些
     本不该被摧毁的东西。正确的结局，沉重的代价。
     读者感受：值得，但心里有个洞。

B. 灰色的真相
   → 凶手有自己的逻辑，受害者未必无辜，
     正义与法律之间存在裂缝。侦探选择了某个答案，
     但不是唯一的答案。
     读者感受：不安、持续思考、没有简单结论。

C. 救赎与和解
   → 案件的核心是一段被误解的关系或一个无法开口的秘密。
     真相揭开不是为了惩罚，而是为了让某些人终于可以放下。
     读者感受：悲伤但释然，像一场迟到的告别。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`结局基调` → 继续第5轮。

## 第5轮：推理趣味

**目的**：确定解谜体验的结构形态——读者与谜题的相对位置。这决定假设链的形状（见 truth_template「假设链规划·变体适配」）。

```
【第5轮：读者和谜题站成什么关系？】

同样是欺骗与揭穿，结构可以完全不同——
读者比侦探知道得多，还是少？侦探靠脚还是靠脑？

A. 本格解谜
   → 读者与侦探信息同步，公平对决。
     快感来自"我也可能猜到"，爽利在最后一环扣上的瞬间。

B. 倒叙推理
   → 开局就让你看见凶手是谁、怎么做的。
     悬念不是"谁做的"，而是"侦探何时抓住、如何证明"——
     你比侦探早半步，又比自己的自信晚半步。

C. 安乐椅侦探
   → 侦探几乎不出门，证据由证词、文书、来访"送上门"。
     头脑是唯一的现场，对话是唯一的追逐。

D. 社会派追问
   → 案件是入口，真正的谜在机构、家族、时代深处。
     节奏更慢更沉，真相揭开时令人悲哀而非惊叹。

E. 惊悚追逐
   → 侦探自己也在危险里，假设快速更迭，
     每一次接近真相都伴随一次代价。

（也可以告诉我你有完全不同的想法）
```

**选择记录**：`推理趣味` → 进入"各轮完成后：生成项目文件"流程。

## 项目文件生成清单

依次生成（读取本包 `templates/` 下对应模板）：

1. **`meta/project_info.md`** - 记录项目名称、类型、各轮选择（含用户原话摘录）、三项基本信息、genre、language
2. **`meta/style_guide.md`** - 风格宪法（读取 `templates/style_guide_template.md`；按本包 craft.md「风格宪法」的正交轴合成：时代轴取语言素材、诡计轴取信息策略、趣味轴取结构形态、张力/基调轴取情感纪律）
3. **`meta/truth.md`** - 真相文档（读取 `templates/truth_template.md`；含「核心骨架」（常驻事实表，从细案蒸馏）与细案分节：「假真相设计」「受害者档案」「假设链规划」「揭示方式约束」「过去的露出纪律」。若用户案件描述为"多年前旧案重揭"类，必须落实「过去的露出纪律」——过去以当前证据形态分散浮出，禁止终章"历史故事块"；第5轮为倒叙推理/安乐椅/社会派/惊悚时，假设链按「变体适配」调整形状）
4. **`meta/clues.md`** - 线索地图（读取 `templates/clues_template.md`；含「总索引」节——一行一条全量登记，此后每次状态变更同步维护）
5. **`meta/characters.md`** - 角色档案（读取 `templates/characters_template.md`，至少包含主角、死者条目、嫌疑人和1-2个关键配角；受害者的深度档案登记在 truth.md「受害者档案」，不进 characters.md）
6. **`meta/outline.md`** - 章节大纲（读取 `templates/outline_template.md`；每章必须包含本章目标、应投线索（CL/RH 编号）、假设操作（建立/强化/推翻 H-X）、核心依据（本章相关的 truth.md 细案分节）、应揭秘密、应拆穿误导、章末钩子，并与 truth.md 的线索投放总表及假设链规划一致；终局结构与尾声章按模板「全书参数」登记——结局基调为"灰色的真相"时优先考虑揭示章+对峙章分设）
7. **`meta/session_log.md`** - 空日志文件，等待第一章完成后填入
8. **`novels/_ledger.md` 追加一行**（跨项目去重账本，机制与查重时机见 `references/init_flow.md` 步骤2/4）——本题材填写口径：
   - **核心悬念**：案件的不可能事件/核心谜面一句话（例："死者死后一小时，钟声里传来了他的声音"）
   - **标志性装置**：核心道具+诡计家族（例："留声机+身份替换"、"延时注水+数字擦除"）
   - ⚠️ 若步骤2账本核对发现同构谜面（同一不可能事件骨架，或道具+诡计家族撞车——尤其"钟声/延时装置/身份顶替"这类高频组合），必须先与用户确认差异化方向再生成文件

## outline 章节节奏说明

全书按**假设周期**推进，而非线索数量的累积：

```
谜团成形 → H1 建立 → （维持性证据）→ H1 被推翻 → H2 建立 → H2 被推翻/修正
→ 证据收敛（真相成为唯一存留解释）→ 推导揭示
```

- 快节奏（当代都市线/封闭场景/惊悚追逐）：每个假设周期 2-3 章
- 慢热（民国线/千禧线/社会派追问）：每个假设周期 3-4 章，允许"积累章"（假设状态不变，但投放维持假设或埋漏洞的证据）
- 封闭场景变体：H1/H2 依次指向在场者，被证据逐一排除
- 每个周期内部：建立/强化假设 → 投放维持性证据 → 推翻证据出现 → 假设被推翻或修正
- 趣味轴变体（第5轮）：倒叙推理/安乐椅/社会派/惊悚的周期与推进媒介适配见 truth.md「假设链规划·变体适配」
- 详细阶段表与变体适配见 truth.md「假设链规划」

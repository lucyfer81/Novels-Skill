# 章节大纲模板

> 使用说明：初始化时根据真相文档（truth.md）生成，是"计划"与"执行"的对照基准。
> 每一章必须有明确的线索/假设/秘密/拆穿计划——没有计划的章节就是失控的章节。
> 章节封存时必须对照本文件核对实际执行情况并回写偏差（见写作循环"章节封存协议"第三步）。

---

# 《[书名]》章节大纲

## 全书参数

- 总章数：[N]（建议 10-14）
- 揭示章：第X章（真相由侦探推导揭示）
- 三幕划分：第一幕 第1-X章 / 第二幕 第X-X章 / 第三幕 第X-X章
- 假设链概览：H1（第X章建立 → 第X章推翻）→ H2（第X章建立 → 第X章推翻）→ 证据收敛（第X-X章）→ 推导揭示（第X章）

## 每章计划

### 第1章 [章节标题]

- **本章目标**：[一句话：这一章在整体结构中完成什么]
- **应投线索**：[CL-XX / RH-XX，或"无"]
- **假设操作**：[建立/强化/推翻 H-X（+ 所用的证据编号 CL/RH-XX）；或"积累章——维持现状"]
- **应揭秘密**：[嫌疑人X的"真正隐瞒的事"，或"无"]
- **应拆穿误导**：[RH-XX，或"无"]
- **章末钩子**：[悬而未决的问题或事件]
- **故事内时间**：[本章覆盖的故事内时间跨度]
- **实际执行**：[封存时回写：已完成 / 偏差内容及原因]

### 第2章 [章节标题]

（每章同构，全部章节逐一列出，不得留空或"待定"；全书必须至少含两次"建立→推翻"的假设操作，与 truth.md 假设链规划一致）

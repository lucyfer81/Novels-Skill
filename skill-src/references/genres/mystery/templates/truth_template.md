## 假真相设计（错误答案）——全书的结构骨架

> 推理小说不是"藏真相最后揭晓"，而是让读者和侦探**先相信一个错误的故事，再用证据亲手推翻它**。
> 每个核心谜题至少设计1-2个假真相（错误解释）。没有假真相的谜题，读者只能"听答案"，不能"推理"。

## 假设链规划（全书结构）

> 全书结构 = 谜团 → 提出假设 → 发现证据 → 推翻假设 → 建立新假设 → 再推翻 → 最终推导真相。
> 以下阶段不可跳过；周期长短按节奏伸缩（快节奏每周期2-3章，慢热3-4章，允许"积累章"）。

| 阶段 | 章节 | 内容 |
|------|------|------|
| 谜团成形 | 第1-X章 | 核心谜面立住；读者手中信息足以提出 H1 |
| H1 建立 | 第X-X章 | 支撑证据投放，H1 成为侦探与读者共同的工作假设 |
| H1 被推翻 | 第X章 | 推翻证据出现，**侦探当着读者推翻自己**（全书关键场景之一） |
| H2 建立 | 第X-X章 | 新证据指向新解释，调查转向 |
| H2 被推翻/修正 | 第X章 | 再次推翻，存活的解释开始收敛 |
| 证据收敛 | 第X-X章 | 排除法与正面证据同时到位，真相成为唯一存留的解释 |
| 推导揭示 | 第X章 | 侦探用已投放线索逐步推导出真相（见下方"揭示方式约束"） |

**变体适配：**
- 封闭场景：可用"逐人排除"变体——H1/H2 依次指向最可疑者，被证据逐一排除
- 局外人卷入：官方结论（警方定性）就是现成的 H1，主角的斗争 = 推翻官方假设
- 侦探认识凶手：侦探的情感盲区成为维持错误假设的理由——推翻假设的同时也在克服自己
- 平行暗线（H-id）：一条贯穿全书的暗线假设（如"死者身份有问题"）与主假设链并行——不参与"建立→推翻"循环，由维持性证据持续强化，第三幕与主链交汇；暗线须有自己的支撑线索编号，不得挤占主链推翻节奏
- 倒叙推理：开局即向读者亮出作案过程——假设链对读者反转为"全知优越感管理"（读者早半步看穿侦探的错，晚半步想到证明方法），对侦探仍为标准链
- 安乐椅侦探：假设链的推进媒介以证词/文书/物证传递为主，侦探行动半径不扩张
- 惊悚追逐：假设周期压短（1-2章/假设），侦探自身危险作为常驻压力源穿插于各周期之间

## 揭示方式约束（揭示章写作铁律）

1. **推导式揭示为默认**：真相由侦探引用已投放线索（CL-XX，须已登记 clues.md）逐步推导呈现——每个推理步骤都有砖可查，读者可以跟着走完
2. **自白的边界**：人物（凶手/证人）只说"不得不说的部分"——动机、情感、证据无法触及的经过。自白不得承担本可由证据完成的推理，篇幅不超过揭示场景的1/3
3. **禁止"讲解模式"**：不得出现"让我把一切从头说起……"式的整段真相讲述；信息以对话攻防、证据呈递、侦探复盘中被逼出、拼出的形式给出
4. **心理诡计变体**：揭示可由叙述翻转完成（视角重置/时间线重排/信息重新排列），但翻转后必须回指已投放的可验证线索——读者先被叙述骗，再发现线索一直在眼前
5. **救赎与和解结局变体**：情感自白可以存在且应当动人，但必须排在推导完成之后——先证明，再倾诉
6. **非逮捕终局变体（灰色真相基调适用）**：推导完成后可另设对峙章——证据出示 → 凶手以灰色逻辑应对（不抵赖、不崩溃、陈述自己的道理）→ 未闭合的出口。对峙章不得引入新证据；侦探的最后一句话留给道德余味，而非胜利宣言。推导章与对峙章在 outline 中分设（见 outline 模板「终局结构」）

## 过去的露出纪律

> 若案件涉及过去事件（旧案/旧怨/多年前的秘密）：纪律管的是**形式**，不是内容——过去照样可以有分量（社会派尤其如此），但不得作为终章集中揭晓的"历史故事块"。

1. **证据形态**：过去的信息以当前案件中的物证、证词矛盾、档案、身体痕迹等形态浮出；禁止"某人开始回忆"式的整段倒叙倾倒
2. **露出即推进**：每次露出必须推动或推翻一个假设（H编号）；不改变任何假设状态的过去信息，不配得到一个场景
3. **分散原则**：过去的关键事实分散在至少3个章节、由不同载体（物/人/档案）给出
4. **可推理性**：终章前读者看到的过去碎片，已足以（在推翻 H1/H2 之后）拼出动机的轮廓——终章只补最后的缺口

# 推理题材：写作/封存/审阅钩子

> 核心协议（writing_loop.md / auto_agents.md）在标注触点处注入本文件对应钩子的全文。
> 投放物分类学（Hard Clue / Red Herring / Atmospheric Clue）见本包 craft.md，此处引用不重定义。

## write_preflight（写作前行为预检）

在涉及凶杀或高风险对抗的场景前，先用一句话回答：
"[受害者]此时的信息量是[X]，他/她的求生本能和处事逻辑，会让他/她做出什么行为？"
如果计划中的剧情与这个答案冲突，必须调整触发条件（让场景在更高的张力点爆发），而不是降低人物智识。

## signal_budget（每章线索投放预算与原则）

- 每章最多投放 1 条关键线索（Hard Clue），可附带 1 条误导性线索（Red Herring）
- 线索投放以 outline.md 本章计划为准（应投 CL-/RH- 编号）；若实际偏离计划，必须显式说明原因（交互模式写入写作后记，自动模式写入 `<segment_meta>`），**禁止无声遗漏**
- 线索是**推理材料**而非伏笔：必须"公平"（回看成立）且**当下可用**（投放时读者即可参与推理），每条关键线索支持双重解释——支撑假真相的读法初读更自然，指向真相的读法回看成立
- 假设操作以 outline.md 本章「假设操作」字段为准：建立/强化/推翻 H-X；推翻必须由证据驱动（可指认 CL-XX），禁止靠说漏嘴/巧合/自白
- 侦探的结论必须引用可指认的已投放线索，按"观察→疑问→验证→判断"推进；禁止"忽然明白"式跳步
- 每次投放后立即更新 `meta/clues.md`（本题材 signal_doc）的状态
- 凶手以嫌疑人身份出场时，其公开言行必须符合 truth.md（本题材 core_doc）的伪装策略与案发后行为线；叙述不得泄露"只有凶手知道的信息"
- 🔴 **编号不入正文**：CL-/RH-/AC- 等登记编号，以及"全书 / 假设链 / 推翻 H / 投放 / 揭示章"等结构术语，只允许出现在 meta 文档与写作后记中；正文与对白一律不得出现——读者读到的是小说，不是线索登记册

## showing_checklist（Showing 自查，仅报命中项）

- 通用：□ 叙述者直接说明人物的情绪 □ 人物说出时代错位的哲理句
- 题材专项：□ 侦探凭直觉宣布结论（未引用已投放线索） □ 讲解模式自白 □ 凶手言行偏离伪装策略 □ 叙述泄露只有凶手知道的信息 □ 侦探言行超出「当前已知信息」边界 □ 叙述替读者下结论（"他不知道的是/这意味着"式全知定论句） □ 对白文艺腔失真（人物说出修辞对称的长句、或说出自己行为的内在逻辑） □ 推理结论只有软证据支点（直觉/气味/印象，无可指认的物证或线索） □ 正文或对白出现登记编号（CL-/RH-/AC-）或结构术语（全书/假设链/推翻 H 等）

## seal_check（章节封存第三步核对）

登记本章实际投放的线索（含正文摘录）并更新状态后，执行三类核对：

1. **投放预算核对**（对照 outline.md 本章计划）：
   - 计划投放的 CL-/RH- 是否已投？未投 → 就地补投，或显式修改 outline 计划并在「章节计划变更记录」中写明原因。**禁止无声遗漏**
   - 计划揭示的嫌疑人秘密是否已揭？计划拆穿的 RH 是否已拆穿？同上
2. **假设链核对**：对照 outline.md 本章「假设操作」——计划建立/强化/推翻的 H-X 是否完成？推翻是否由证据驱动（可指认 CL-XX，而非说漏嘴/巧合/自白）？未完成 → 就地补写，或显式修改 outline 计划并记录原因。**禁止无声遗漏**
3. **揭示章断言（双断言 + 证据来源断言）**：若下一章进入真相揭示，**或本章即揭示章**（outline 中第三幕收拢/结局章）：
   - 逐条断言所有 Hard Clues 状态为"已投放"——未投放的必须在本章内补投
   - 逐条断言 truth.md 假真相设计中所有 H 均已按计划建立并被证据推翻——有缺口的在本章内补齐（该补的推翻必须由证据完成）
   - 🔴 **证据来源断言（本章即揭示章时逐件执行）**：核对揭示章正文中侦探出示/引用的**每一件证据**——每件都必须能在 clues.md 中指认登记编号。出现未登记的"天降证据"→ 二选一：属计划内线索 → 在本章或前文补投其铺垫并登记；属计划外 → 改写为引用已投放线索。**禁止保留"揭示章首次亮出"的证据**

核对完成后，在 outline.md 中定位**本章标题小节**（`### 第X章`），将结果写入该小节下的「实际执行」字段（已完成 / 偏差及原因）；🔴 严禁写入其他章节小节的字段。

## review_dims（责任编辑 B 维度：读者视角模拟）

切换至不持有 truth.md 的视角。
- 此刻读者的**领先假设**是什么？支撑它的是哪些已投放线索？
- 认真的读者能否自己组织一次推理（哪怕推出的是错误答案——这正是假真相在起作用）？
- 哪个细节"太重要了"？哪里感到困惑？
- 本章的推理/发现场景中，气氛描写是否打断了推理节奏？
- 若本章为对峙/揭示/推翻假设章：推理与对峙段的比喻与形容词密度是否显著高于样板句式（高潮章是风格崩坏高发区，发现即定级 🔴）
- 正文是否残留登记编号（CL-/RH-/AC-）或结构术语（全书/假设链等）——它们只应存在于 meta 与写作后记

## full_review（全稿两轮审阅题材部分）

### 第一轮专项核查（E 项·假设链核查）

- 假真相（H1/H2）是否真实建立过——读者是否曾有机会相信并投入一个错误解释？
- 每个 H 是否被证据推翻（而非被作者遗忘、被自白取代、或从未真正成立）？
- 侦探全书是否至少一次当着读者推翻自己？
- 揭示章是推导式还是讲解式？侦探引用的每条证据是否均已投放（clues.md 可查）？自白是否越界承担了证据功能？
- 过去/背景信息是否以当前证据形态分散浮出？是否存在终章"历史故事块"式的集中倾倒？
- 推理/发现/反转场景中，气氛描写是否打断了推理节奏？

### 第二轮输出格式（推理版）

**目标**：从资深推理小说编辑视角判断整部作品的出版价值与核心问题。
**视角**：不持有 truth.md，以第一次读稿的编辑身份进行判断。
**输入**：全部 `{project_dir}/drafts/chXX.md` 文件

```
【第二轮审阅：文学编辑评审】

**核心判断**
（1-2句话，直接给出总体评价）

**真正的优势**
（2-3点，每点必须引用具体章节或段落作为依据，泛泛而谈不算数）

**需要解决的问题**
（按严重程度排序，每条说明：是什么问题 / 在哪里出现 / 为什么是问题 / 建议方向）

**读者体验预判**
（这部作品会在哪个读者群体中引发什么反应？包括可能的正面和负面反馈）

**如果只能改一件事**
（你认为最影响作品质量的单一问题）
```

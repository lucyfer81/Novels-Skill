# 角色档案模板

> 使用说明：根据初始化时的选择和真相文档，填充以下模板。
> 每个角色必须填写"独立存在理由"——如果填不出来，说明这个角色是"工具人"，需要重新设计或合并。
> 删除所有模板说明文字，只保留填充后的内容。

## 角色关系速览

```
[角色A] ——[关系]—— [角色B]
   |                     |
   +——[关系]—— [角色C]   +——[关系]—— [角色D]
```

> 在章节推进过程中，封存时持续更新各角色的「当前状态」「当前已知信息」「出场记录」字段。
> 每个角色的说话方式和称谓必须保持一致——如果某角色的对白风格或称谓漂移，在 /edit 时修正。
